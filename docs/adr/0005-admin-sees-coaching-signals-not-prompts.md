# Admin sees per-Member coaching signals, never raw Prompts

The Admin sees each Member's Efficiency Score trend, frequently broken Rules and Suggestion accept rate, so they can coach individuals. Prompt text stays private unless the Member publishes it to the Prompt Library. Each Member sees exactly what the Admin sees about them. No rankings or leaderboards. Chosen over full visibility (feels like surveillance, kills adoption) and aggregates-only (Admin can't coach).
